#Instruction on how to crop the OME TIFF image with QuPath

1.Upload .ome.tif image
2.Draw ROI and select >Lock
3.File>Export images> OME TIFF
4.When in OME TIFF choose : Compression LZW (lossless) , Pyramidal downsample = 2 ( same as Level parameter of config.yaml file ), Tile size = 256,
Parallelize export OK, All z-slices  OK
5. Save the image and rename WITHOUT writing ".ome.tif". They are already included by QuPath. "tif" will never show up but it is there. Important : rename using "cropped" , e.g. "TC70_cropped".
