PLOTS

**QC plot**: Violin plot displaying key quality control metrics that assess the transcriptomic complexity and sequencing depth of individual cells in the dataset. The plots shows the distribution of unique genes detected per cell (nFeature) and the total number of RNA molecules or UMIs captured per cell (nCount).

**SingleR_predictions_QC**: Heatmap displaying the prediction scores from SingleR's automated cell type annotation algorithm. The scores show the confidence level for each predicted cell type across all identified clusters. Higher scores (closer to 1) indicate stronger evidence for a particular cell type assignment based on reference single cell data.

**Spatial_SingleR**:  Spatial UMAP plot displaying cells organization into transcriptionally distinct clusters annotated after SingleR data processing. The UMAP plot displays cluster labels generated through quality control filtering, SCTransform normalization, graph-based clustering (FindNeighbours and FindClusters), and automated cell type annotation using the SingleR reference-based method.

**spatialobj_plot**: Spatial representation of the tissue sample showing the physical location of each cell as individual point, preserving the native tissue architecture and spatial context. This visualization is generated by creating a custom dimensional reduction object from the original spatial coordinates using CreateDimReducObject, followed by filtering to retain only cells with detectable RNA counts (nCount_RNA > 0).

**UMAP_SingleR**: UMAP plot revealing the transcriptomic relationships between cells, where similar cell types cluster together in reduced dimensional space. UMAP plot where each point represents a cell colored by its automated cell type assignment from SingleR, allowing visualization of how well the reference-based annotations align with the data-driven clustering structure.

TABLES

**Laplacian score**: Table in CSV format with two columns "Z_slice" and "Sharpness_score" representing the sharpness value assigned to each z-slice of the z-stack. The higher the sharpness score the higher the number of strong edges characterizing the local curvature of the features masured by the Laplacian algorithm.

**z_slice_measurements**: Table in CSV format displaying the information (Image, Object ID, Object type, Name, Classification,Parent,Region of interest/ROI, Centroid X Âµm, Centroid Y Âµm, Z index, Area Âµm^2 and Perimiter Perimeter Âµm) of the whole Z-stack. The Z index column enphasizes the number of single z-slices with the z-stack. 

**average_nuclear_expansion**: CSV file displaying the image tailored average nuclear expansion in µm. This measurement is automatically imputed by STAT3D during the cell-to-transcript mapping step. The user can modify this measurement via the NUCLEAR_EXPANSION_SET parameter in the config.yaml file.

**nuclei_diameter** : CSV file displaying the average diameter of the nuclei in µm. This value is automatically translated into pixels based on the value set in the "PIXEL_SIZE" parameter of the configuration file. The pixel value calculated by STAT3D is used during Cellpose segmentation. This measurement can be overwritten by the user via the NUCLEI_DIAMETER parameter (µm) in the config.yaml file, this value  will be transformed into pixel value by STAT3D according to the "PIXEL_SIZE" parameter and subsequently imputed in Cellpose.

DRAFT

**Image pre-processing**
1. STAT3D generates z_slice_measuremet CSV file to identify and proof the architecture of the z-stacks in the pyramidal image.
2. STAT3D generates one TIF image foe every z-slice of the z stack. These images visually demonstrate the sharpness and quality of each z-slice image in the z-stack.The images are stored in one folder called "export".
3. STAT3D computes the laplacian score for every image of the z-stacks. The results are displaied during the pipeline run and stored in a CSV file named "Laplacian score".
4. STAT3D selects the two most sharp z-slices resulted from the Laplacian score calculation and creates a newer and smaller OME.TIF format image which will represent the new base for the rest of the analysis.This image is names as "morphology.ome_STAT3D".
5. STAT3D uses morphology.ome_STAT3D to measure with QuPath Image Analysis Software the nuclei characteristics such as average diameter , average expansion and average minimum distance. These parameters are used by STAT3D to tailor the subsequent steps.

**Segmentation**
6. STAT3D performs Cellpose nuclear segmentation on morphology.ome_STAT3D with the previously calculated average diameter. STAT3D enables 3D segmentation via "cellpose_do_3d" parameter.The output of the segmentation are one TIF file displaying Cellpose identified masks ( "morphology.ome_STAT3D_cp_masks.tif") and one numpy array containing the spatial information of Cellpose masks ("morphology.ome_STAT3D_seg.npy).

**Cell-to-transcripts mapping with tailored cell neighbourhood search**

7. STAT3D performs cell-to-transcript mapping to correctly assign each transcript to the neares cell. This step uses the average nuclear expansion parameter previously calculated by the pipeline.This step outputs three gzipped files named "matrix.mtx", features.tsv.gz" and "barcodes.tsv.gz". The matrix.mtx.gz file represents sparse matrix encoding feature-by-cell counts, features.tsv.gz lists the names of the target transcripts and barcodes.tsv.gz displays each cell id and its 3D spatial localization. The three outputs are the foundament for the generation of Seurat spatial object.


**Seurat spatial object with SingleR automated annotation**

8. STAT3D generates one Seurat spatial object with the following files : matrix.mtx, features.tsv.gz and barcodes.tsv.gz, through the Seurat function Read10x. The STAT3D seurat object is named "sp_obj.rds".The sp_obj.rds file contains all the spatial information of the cells with nCounts>0. Subsequently STAT3D proceeds with downstream analysis of sp_obj.rds perfroming Normalization and scaling with SCTransform, pPrincipal component analysis (PCA on 30 principal components), runs the Uniform Manifold Approximation and Projection (UMAP, on 30 dimensions), builds a k-nearest-neighbor graph of cells in reduced dimensional space of 30 dimensions based on PCA reduction,  identifies communities of cells in the shared nearest-neighbor (SNN) graph using modularity optimization at 0.3 resolution.

9. STAT3D performs SingleR annotation on the seurat object and saves it as "singler.rds". This new Seurat spatial object contains all the cells annotated according to the dataset of choice within the meta.data slot named as "singleR.labels".
