### PLOTS

**QC plot**: Violin plot displaying key quality control metrics that assess the transcriptomic complexity and sequencing depth of individual cells in the dataset. The plot shows the distribution of unique genes detected per cell (nFeature) and the total number of RNA molecules or UMIs captured per cell (nCount).

**SingleR_predictions_QC**: Heatmap displaying the prediction scores from SingleR's automated cell type annotation algorithm. The scores indicate the confidence level for each predicted cell type across all identified clusters. Higher scores (closer to 1) reflect stronger evidence for a particular cell type assignment based on the reference single-cell data.

**Spatial_SingleR**: Spatial projection displaying the organization of cells into transcriptionally distinct clusters following SingleR annotation. This plot visualizes cluster labels generated through quality control filtering, SCTransform normalization, graph-based clustering (FindNeighbors and FindClusters), and automated cell type annotation using the SingleR reference-based method.

**spatialobj_plot**: Spatial representation of the tissue sample showing the physical location of each cell as an individual point, preserving the native tissue architecture and spatial context. This visualization is generated by creating a custom dimensional reduction object from the original spatial coordinates using `CreateDimReducObject`, followed by filtering to retain only cells with detectable RNA counts (nCount_RNA > 0).

**UMAP_SingleR**: UMAP plot revealing the transcriptomic relationships between cells, where similar cell types cluster together in a reduced dimensional space. Each point represents a cell colored by its automated cell type assignment from SingleR, allowing visualization of how well the reference-based annotations align with the data-driven clustering structure.

### TABLES

**Laplacian score**: Table in CSV format containing two columns, "Z_slice" and "Sharpness_score", representing the sharpness value assigned to each z-slice of the z-stack. A higher sharpness score indicates a greater number of strong edges characterizing the local curvature of features measured by the Laplacian algorithm.

**z_slice_measurements**: Table in CSV format displaying measurement details (Image, Object ID, Object type, Name, Classification, Parent, Region of interest/ROI, Centroid X µm, Centroid Y µm, Z index, Area µm^2, and Perimeter µm) for the entire Z-stack. The Z index column emphasizes the specific z-slice number within the stack.

**average_nuclear_expansion**: CSV file displaying the image-tailored average nuclear expansion in micrometers (µm). This measurement is automatically computed by STAT3D during the cell-to-transcript mapping step. The user can modify this measurement via the `NUCLEAR_EXPANSION_SET` parameter in the `config.yaml` file.

**nuclei_diameter**: CSV file displaying the average diameter of the nuclei in micrometers (µm). This physical value is automatically converted into pixels by the pipeline based on the `PIXEL_SIZE` parameter defined in the configuration file. The resulting pixel value is then used by STAT3D to guide Cellpose segmentation. This measurement can be overwritten by the user via the `NUCLEI_DIAMETER` parameter (in µm) in the `config.yaml` file; the pipeline will automatically transform this custom value into pixels according to the `PIXEL_SIZE` before passing it to Cellpose.

### DRAFT

**Image pre-processing**

1. STAT3D generates a `z_slice_measurements` CSV file to identify and assess the structural integrity of the z-stacks in the pyramidal image.
2. STAT3D generates a TIF image for every z-slice of the z-stack. These images allow for visual inspection of the sharpness and quality of each slice. The images are stored in a folder named "export".
3. STAT3D computes the Laplacian score for every image in the z-stacks. The results are displayed during the pipeline execution and stored in a CSV file named "Laplacian score".
4. STAT3D selects the two sharpest z-slices based on the Laplacian score calculation and creates a new, reduced OME.TIFF image which serves as the base for downstream analysis. This image is named "morphology.ome_STAT3D".
5. STAT3D uses "morphology.ome_STAT3D" to measure nuclei characteristics—such as average diameter, average expansion, and average minimum distance—using QuPath Image Analysis Software. These parameters are used by STAT3D to tailor the subsequent processing steps.

**Segmentation**
6. STAT3D performs Cellpose nuclear segmentation on "morphology.ome_STAT3D" using the previously calculated average diameter (converted to pixels). STAT3D enables 3D segmentation via the `cellpose_do_3d` parameter. The outputs of the segmentation include a TIF file displaying Cellpose-identified masks ("morphology.ome_STAT3D_cp_masks.tif") and a numpy array containing the spatial information of the masks ("morphology.ome_STAT3D_seg.npy").

**Cell-to-transcripts mapping with tailored cell neighbourhood search**
7. STAT3D performs cell-to-transcript mapping to accurately assign each transcript to the nearest cell. This step utilizes the average nuclear expansion parameter previously calculated by the pipeline. The output consists of three gzipped files: "matrix.mtx", "features.tsv.gz", and "barcodes.tsv.gz". The `matrix.mtx.gz` file represents a sparse matrix encoding feature-by-cell counts; `features.tsv.gz` lists the names of the target transcripts; and `barcodes.tsv.gz` displays each cell ID along with its 3D spatial localization. These three files form the foundation for generating the Seurat spatial object.

**Seurat spatial object with SingleR automated annotation**
8. STAT3D generates a Seurat spatial object using the `Read10x` function on the output files (matrix, features, barcodes). The resulting object is saved as "sp_obj.rds" and contains spatial information for all cells with detected counts (nCounts > 0). Subsequently, STAT3D proceeds with downstream analysis of "sp_obj.rds", performing normalization and scaling via SCTransform, Principal Component Analysis (PCA on 30 principal components), Uniform Manifold Approximation and Projection (UMAP on 30 dimensions), and construction of a k-nearest-neighbor graph in the reduced dimensional space. Finally, it identifies cell communities in the shared nearest-neighbor (SNN) graph using modularity optimization at a resolution of 0.3.
9. STAT3D performs SingleR annotation on the Seurat object and saves the result as "singler.rds". This new Seurat spatial object contains all cells annotated according to the reference dataset, stored within the `meta.data` slot as "singleR.labels".
